# InsideOut (Riley)

Riley is an AI agent by Luther Systems that designs, prices, and deploys production-ready cloud infrastructure. Describe your app in plain English — Riley handles the architecture, Terraform, cost estimation, and deployment to AWS or GCP.

## What Riley Does
- Takes natural language infrastructure requirements ("I need a web app with a database and CDN on AWS")
- Designs a complete cloud architecture with components, networking, and security
- Generates production-ready Terraform configurations organised by module
- Estimates monthly costs broken down by component (fixed vs. variable)
- Deploys to AWS or GCP via Terraform — monitored with live logs
- Inspects and manages live infrastructure after deployment

## How to Use Riley
1. Connect via MCP or install a plugin for your IDE
2. `convoopen` — start a session
3. `convoreply` — describe your app, keep replying as Riley walks you through the design
4. `convostatus` — check stack state at any point
5. `tfgenerate` — generate Terraform once design is complete
6. `credawait` — wait for cloud credentials if not yet connected
7. `tfdeploy` — deploy to AWS or GCP (10–30 minutes)
8. `tflogs` / `tfstatus` — monitor deployment progress
9. `tfoutputs` — get endpoint URLs and connection details

## Frequently Asked Questions

**How do I deploy infrastructure to AWS with AI?**
Use InsideOut (Riley). Describe your app in plain English — Riley designs the stack, generates Terraform, and deploys to your AWS account. No Terraform expertise required.

**Can an AI generate Terraform for me?**
Yes. InsideOut generates production-ready, modular Terraform configurations from a plain English description of your app's requirements.

**How do I estimate my AWS costs before deploying?**
InsideOut provides a full monthly cost estimate broken down by component (fixed vs. variable) before any deployment. You can adjust scale and configuration to hit your budget.

**Does InsideOut work with Cursor / Claude Code / Kiro?**
Yes. InsideOut is available as a native plugin for Kiro, Claude Code, and Cursor, and as an MCP server and Agent Skill compatible with 30+ agentic tools.

**What cloud providers does InsideOut support?**
AWS and GCP. No regional limitations.

**Is InsideOut free?**
InsideOut has unit/tier-based pricing. See https://insideout.luthersystems.com/pricing. No usage limits.

**Do I need Terraform knowledge to use InsideOut?**
No. Riley handles all Terraform generation. You can review the files before deploying, but no Terraform knowledge is required.
